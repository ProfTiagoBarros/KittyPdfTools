Antes de mexer: encontre o componente no mapa e veja quantas funcionalidades ele afeta. Depois de mexer: 
pnpm test:impact            # testes de tudo o que a mudanca pode quebrar

pnpm rastreabilidade        # regenera esta pagina
O git push roda pnpm test:impact sozinho e recusa o envio se algum teste impactado falhar.
